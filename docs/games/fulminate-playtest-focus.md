# Fulminate — the play-test region split

`bin/playtest-preflight Fulminate` reads this file and passes it as the round's `focus`.
It lives here, committed, rather than being re-authored into a round's arguments each
time.

Fulminate is nine rooms, and the reflex reading is that a game this small cannot be
split by place. That reading cost the 2026-08-17 round a whole axis: it split by clock
alone, and its own coverage section
(`docs/games/fulminate-playtest-2026-08-17.md:371-460`) records what the vertical gap
took with it — four of nine rooms worked by exactly one charter, **both** scheduled
arrival lines that printed in zero transcripts, **both** `talk.shows` rows that never
fired anywhere, and one suspect never examined by anybody. A 26-turn probe of
`up, west, z×24` filled five of those blank cells afterwards. It was never expensive; it
was unassigned. So this file splits on **both** axes.

**Regions are written in affordances, never in room names.** A blind explorer is handed
its own region verbatim, so a display name here is a room the firewall was supposed to
withhold and just gave away. The game's own opening paragraph tells the player the
stairs go up, so "the floor above the one you start on" leaks nothing; the nine names in
`Sources/Fulminate/Fulminate.swift` leak everything.
`node .claude/workflows/playtest.dryrun.mjs` asserts that property against the generated
prompts, which is the only cheap place to check it.

The `|` separates regions. Every region carries a row for each charter that can act on
it, because a seat with no row in the plan falls back to instinct — and the seat that
did that last round spent three quarters of its probes inside the first of the two
windows it owned.

**No save slots.** Every region here is walkable from a cold start inside a handful of
turns, so this file ships no `restore` apparatus and no reproducer in this round should
need one.

**A split of a nine-room game must still name a seat for the rooms outside every
region.** The 2026-08-17 round left the vertical axis unassigned; the 2026-08-26 round
fixed that and left the early ground floor unassigned instead, and the arithmetic is
identical either way. Six of nine seats drew the floor above the one you start on, no
region owned the floor you start on before the noise or the outbuilding behind the
house, and **those four rooms produced zero findings between them — including the one
that got zero commands in 1,288 turns, which holds the victim, a death ending nobody
has ever produced, and a scheduled branch that fired eighty-one times and never once
took it.** The cause was not testers who did not try; it was a plan with a hole in it.
Hence R4, and hence the standing residual line every seat now reads: rooms no region
names are owned by nobody, and are yours if your own region runs dry. Two guards, because
declaring a fourth region only closes the hole this file had — the residual closes the
next one.
